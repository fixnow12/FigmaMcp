# FigmaMcp

**Создавайте и редактируйте макеты Figma обычными словами — через Codex или OpenCode.**

FigmaMcp соединяет AI-ассистента с открытым файлом в Figma Desktop. Вы описываете задачу в чате — ассистент читает макет, меняет слои и показывает результат. Названия команд и JSON знать не нужно.

В комплекте — локальный MCP-сервер, который передаёт команды ассистента, и плагин **Figma Desktop Bridge — Auto**, который выполняет их в Figma. После установки Bridge подключается автоматически, без Figma API-токена и кодов сопряжения.

## Возможности

- **Разобраться в макете:** прочитать слои, тексты и оформление, проверить Auto Layout, получить скриншот.
- **Поправить экран:** заменить тексты, цвета и шрифты, настроить размеры и отступы, скопировать или переместить блоки.
- **Создать новый вариант:** собрать экран с нуля или воссоздать существующий рядом, в отдельном фрейме с редактируемыми слоями.
- **Использовать дизайн-систему:** найти локальные стили и переменные, привязать доступные Variables, вставить экземпляры локальных или опубликованных библиотечных компонентов по их ключам.
- **Связать экраны:** добавить ссылки, переходы, оверлеи, прокрутку к блоку и действия «назад» и «закрыть».
- **Получить ресурсы:** экспортировать иконки в SVG и исходные изображения из заливок.
- **Работать со страницами:** переключать страницу, менять её фон и режимы переменных, задавать обложку файла.

Можно подключить несколько файлов: запустите Bridge в каждом и укажите ассистенту нужный файл по ссылке. В окне плагина видны состояние подключения, текущая операция и журнал результатов.

## Установка

Понадобятся **macOS или Windows 10/11**, [Node.js 20+](https://nodejs.org/), [Git](https://git-scm.com/), Figma Desktop и Codex либо OpenCode. Для автоматической установки в Codex команда `codex` должна быть доступна в терминале.

### 1. Скачайте проект и запустите установщик

В Terminal на macOS или PowerShell на Windows:

```bash
git clone https://github.com/fixnow12/FigmaMcp.git
cd FigmaMcp
```

**macOS:**

```bash
bash scripts/install.sh
```

**Windows:**

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Установщик загрузит зависимости, выполнит проверки, подготовит плагин Figma и зарегистрирует плагин Codex, если найдёт команду `codex`.

### 2. Добавьте плагин в Figma

В Figma Desktop откройте **Plugins → Development → Import plugin from manifest…** и выберите `manifest.json` по пути из установщика:

- **macOS:** `~/.figma-local-bridge/figma-plugin/manifest.json` — нажмите `⌘⇧G` в диалоге выбора файла и вставьте путь;
- **Windows:** `%USERPROFILE%\.figma-local-bridge\figma-plugin\manifest.json`.

Импорт нужен один раз. Используйте персональный `manifest.json`, а не `manifest.template.json` из исходников.

### 3. Подключите AI-ассистента

**Codex:** после установки перезапустите приложение, откройте папку `FigmaMcp` и создайте новую задачу. MCP добавляется вместе с плагином.

<details>
<summary>Если регистрация плагина Codex была пропущена</summary>

Убедитесь, что команда `codex` доступна, и выполните из корня проекта:

```bash
codex plugin marketplace add .
codex plugin add figma-local-bridge@figma-mcp
```

Перезапустите Codex и создайте новую задачу. Отдельная регистрация через `codex mcp add` не нужна.

</details>

**OpenCode:** откройте корневую папку `FigmaMcp`, где лежит `opencode.json`, и создайте новый чат. MCP уже настроен в проекте.

## Первый запрос

Откройте нужный файл в Figma и запустите **Plugins → Development → Figma Desktop Bridge — Auto**. Оставьте окно плагина открытым, выделите фрейм и напишите ассистенту:

> Прочитай выделение в Figma и покажи скриншот.

При первом обращении Bridge подключится автоматически. Когда ассистент прочитает нужный фрейм и покажет скриншот, можно переходить к правкам.

## Примеры запросов

> Замени текст кнопки на «Продолжить» и сделай отступы по 16 px.

> Проверь Auto Layout выделенного блока и исправь отступы.

> Воссоздай выделенный экран рядом в отдельном фрейме, сохрани шрифты и оформление. Оригинал не меняй.

> Создай вариант этого экрана: замени список способов оплаты кнопкой «Продолжить», а заголовок — на «Поддержать фонд».

> Сделай пункты оглавления ссылками на соответствующие экраны, а кнопку «Помощь» — ссылкой на сайт.

## Ограничения

- **Воссоздание экрана требует проверки.** При реконструкции экземпляры компонентов становятся обычными фреймами, а привязки к Variables — текущими значениями. Сравните результат со скриншотом исходника. Обычное копирование блоков сохраняет экземпляры и привязки.
- **Некоторые свойства останавливают реконструкцию:** видеозаливки, сеточная раскладка Grid, сдвиг геометрии (skew), отражённые контейнеры и недоступные шрифты. Ассистент получает список проблемных слоёв; можно выбрать меньший блок для работы.
- **Библиотечные ресурсы должны быть доступны.** Полный поиск по всем внешним компонентам и стилям не поддерживается. Правка оригиналов компонентов требует отдельного подтверждения влияния на библиотеку.
- **Имя файла меняется вручную в Figma.** Bridge может прочитать и проверить его, а также установить обложку.

Подробности: [воссоздание экранов](plugins/figma-local-bridge/skills/figma-local/references/reconstruction.md), [компоненты и переменные](plugins/figma-local-bridge/skills/figma-local/references/design-operations.md), [ссылки и переходы](plugins/figma-local-bridge/skills/figma-local/references/interactions.md), [страницы и обложка файла](plugins/figma-local-bridge/skills/figma-local/references/file-context.md). Предложения по новым функциям собраны в [планах развития](docs/functionality-roadmap.md).

## Обновление и помощь

В папке проекта выполните `git pull --ff-only` и повторите команду установки для своей ОС. Затем закройте Bridge и все AI-приложения, использующие этот MCP, подождите минуту и откройте их заново. Начните новый чат или задачу. Повторный импорт manifest при прежнем пути не нужен.

Если соединения нет, проверьте, что Bridge запущен в нужном файле, и нажмите **Подключить**. Напишите ассистенту: «Проверь подключение к этому файлу через figma-local». Если ассистенту недоступен сам инструмент, повторите установку и перезапустите AI-приложение.

После тайм-аута сначала проверьте макет: изменение могло выполниться. Не повторяйте ту же правку, пока не выяснен результат.

Команды диагностики, проверка версий и тесты — в [руководстве по обслуживанию](docs/maintenance.md). Окно плагина и экспорт журнала описаны в [документации Bridge](plugins/figma-local-bridge/src/figma-plugin/README.md).

## Подключение и данные

Мост работает на вашем компьютере через `127.0.0.1`, с проверкой ключей и шифрованием соединения. Обработка данных AI зависит от выбранного ассистента и модели: локальное подключение к Figma само по себе не означает локальную обработку моделью.

Персональный каталог `~/.figma-local-bridge` содержит ключи — не публикуйте и не пересылайте его. Закрытие окна Bridge отключает доступ к файлу через этот плагин. [Подробнее о безопасности](plugins/figma-local-bridge/AUTO_CONNECTION.md).
