# Figma Desktop Bridge

Локальный development-плагин для связи Figma Desktop с `figma-local` MCP. Версия плагина синхронизирована с пакетом `figma-local-bridge`: **0.2.2**.

## Архитектура

```text
OpenCode / Codex
      ↕ stdio
figma-local MCP
      ↕ ws://localhost:9223–9232 + mutual HMAC pairing
Figma Desktop Bridge
      ↕ postMessage
Figma Plugin API
```

Плагин работает только через loopback-интерфейс локальной машины. В нём нет удалённого relay, внешнего режима подключения или сетевых разрешений для сторонних серверов.

## Установка

1. Откройте Figma Desktop.
2. Выберите **Plugins → Development → Import plugin from manifest…**.
3. Укажите `plugins/figma-local-bridge/figma-plugin/manifest.json` из этого репозитория.
4. Откройте нужный Figma-файл.
5. Запустите **Plugins → Development → Figma Desktop Bridge** и оставьте окно плагина открытым.

После изменения `manifest.json`, `code.js` или `ui.html` импортируйте manifest повторно: Figma кеширует файлы development-плагина.

## Локальное сопряжение

При первом обращении MCP возвращает код вида `9223:<secret>`.

1. Скопируйте код целиком.
2. Вставьте его в поле **Local pairing code**.
3. Нажмите **Pair**.

Код привязан к конкретному порту и текущему процессу MCP. До завершения взаимной HMAC-проверки плагин не отправляет сведения о файле и не принимает команды. Secret хранится только в памяти окна плагина и используется для защищённых переподключений в рамках текущего сеанса.

## Подключение

- MCP-сервер занимает первый свободный порт в диапазоне `9223–9232`.
- Плагин проверяет весь диапазон и может поддерживать несколько локальных MCP-процессов.
- Кнопка **Pause** закрывает локальные соединения и останавливает поиск.
- Кнопка **Resume** или **Try again** запускает поиск заново.
- `+` открывает журнал активности.

## Безопасность

- Разрешены только `http://localhost` и `ws://localhost` на портах `9223–9232`.
- Сервер слушает IPv4 loopback `127.0.0.1`.
- До аутентификации блокируются метаданные файла, переменные, события и команды.
- Для каждой WebSocket-сессии используется новый challenge и направленные HMAC-доказательства клиента и сервера.
- Не публикуйте локальные порты через port forwarding и не передавайте pairing-код другим людям.

