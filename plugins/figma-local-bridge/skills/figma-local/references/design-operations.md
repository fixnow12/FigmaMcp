# Готовые блоки и дизайн-система

Все изменяющие операции используют файл и страницу, закреплённые в начале вызова. Перед записью проверь источник через `inspect_selection`. `screenshot: true` добавляет PNG первой копии или первого изменённого узла. Статусы ошибок и отката такие же, как у `patch_nodes`.

## Копирование

`clone_nodes` принимает `copies`: каждый элемент содержит `sourceId`, новый корневой `key` и при необходимости `parentId`, `name`, `index` и `position: {x, y}`. Без `parentId` используется родитель источника; без `index` копия добавляется в конец.

Копируются оформление, экземпляры и существующие привязки; все служебные ключи копии заменяются. В результате `copies[].nodes` содержит `{sourceId, id, key}` для каждого слоя. Для следующих правок используй ID или ключи из этого результата, а не из источника.

По умолчанию разрешено копирование до 500 узлов суммарно; `maxNodes` можно явно увеличить до 2000. Определения компонентов, внутренние слои экземпляров и вставка внутрь копируемых источников в одном пакете отклоняются. Для компонентов используй `use_component`.

## Перенос и порядок

`move_nodes` принимает `moves` с `id` и хотя бы одним из полей: `parentId`, `index`, `position`. Родители — `PAGE`, `FRAME` или `SECTION` текущей страницы. ID узлов сохраняются.

`index` отсчитывается от нуля и означает конечное место узла после данного шага пакета. Шаги выполняются по порядку. Например, из `[А, Б, В]` перенос А на `index: 2` даёт `[Б, В, А]`. Результат возвращает индексы после всего пакета.

Без `index` перенос добавляет узел в конец. Если меняется только `position` в том же родителе, порядок сохраняется. `position` задаёт координаты относительно нового родителя и допускается в свободной раскладке или для слоя с абсолютным позиционированием. В обычном Auto Layout используй `index`; размеры Fill требуют Auto Layout у нового родителя.

Перемещение из групп не поддержано: пустая группа может автоматически удалиться и затруднить откат. Родителя и его потомков перемещай отдельными пакетами. Определения компонентов и внутреннюю структуру экземпляров эта операция не меняет.

## Поиск

`find_assets` фильтрует имена по подстроке без учёта регистра. `limit` по умолчанию 50, максимум 200; продолжение — через `offset: nextOffset`. Пагинация относится к текущему состоянию файла, поэтому после изменений начни поиск заново.

- `nodes`: обычные слои, при необходимости ограниченные `types`.
- `components`: определения компонентов на выбранных страницах; результат содержит `id`, `libraryKey`, свойства и варианты. Для локального источника в `use_component` передавай `sourceId`.
- `styles`: локальные стили файла с ID и основными свойствами. Этот инструмент не применяет стили.
- `variables`: локальные переменные, их ID, типы, значения по режимам и сведения о коллекциях.
- `library_collections`: доступные библиотечные коллекции Variables.
- `library_variables`: метаданные переменных конкретной коллекции, заданной через `collectionKey`.

Для `nodes/components` доступны `scope: "page"` (по умолчанию) и `scope: "file"`. Остальные ресурсы относятся к файлу. Поиск не импортирует ресурсы и не редактирует библиотеку. Полный внешний каталог компонентов и стилей через этот путь недоступен.

## Привязка Variables

`bind_variables` принимает `bindings` с `nodeId`, `field` и `variableId`. ID получают из `find_assets` или существующих `boundVariables` в подробном чтении. Библиотечный `key` не заменяет `variableId`: переменная должна быть уже доступна в файле; импорт внешних переменных этим инструментом пока не выполняется.

Для `fills/strokes` укажи `paintIndex` (по умолчанию 0). Поддержана существующая заливка `SOLID`; остальные paints сохраняются. Числовые свойства требуют `FLOAT`, `visible` — `BOOLEAN`, `characters` — `STRING`, цвет — `COLOR`. Размеры и размер шрифта должны быть положительными; значения проверяются для текущего режима целевого слоя.

`variableId: null` снимает привязку. Смешанные значения целого текстового узла и смешанные привязки пока отклоняются. Операция изменяет только связь на слоях, а не значения или режимы самих переменных.

Правка оригинального компонента или его потомков по умолчанию заблокирована. `allowComponentChanges: true` допустим только после явного подтверждения пользователем влияния на библиотеку. Флаг не является заменой такого подтверждения.
