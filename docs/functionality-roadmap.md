# Дальнейшее развитие Bridge

## Добавлено 10 сентября 2026

Текстовые URL/NODE-ссылки на весь текст и диапазоны; прототипные NAVIGATE, OVERLAY,
SCROLL_TO, URL, BACK, CLOSE; простые анимации; пакетная настройка с dryRun, откатом,
защитой компонентов и чтением реальных связей. Это закрывает задачу кликабельного
оглавления и меню в Figma Design.

## Предлагаемый порядок следующих улучшений

| Приоритет | Функция | Польза и критерий готовности |
| --- | --- | --- |
| 1 | Аудит навигации | Отчёт об удалённых целях, экранах без входящих связей и отсутствии пути назад; с явной полнотой обхода. Отличать намеренно изолированные экраны от ошибок. |
| 2 | Перенос связей при воссоздании | По mapping заменить внутренние ID на новые; внешние связи сохранять только явно. Ни одна ссылка копии не должна неожиданно вести в исходник. |
| 3 | Сборка оглавления по выбранным фреймам | Предпросмотр списка «пункт → экран», затем один пакет ссылок. Не выбирать цель только по совпадению имени. |
| 4 | Стартовые точки прототипа | Создание и чтение отдельных пользовательских сценариев; сохранение существующих starting points. |
| 5 | Интерактивные компоненты и состояния | CHANGE_TO, затем условия и переменные прототипа. Отдельные проверки совместимости variants и подтверждение правок оригиналов компонентов. |
| 6 | Журнал изменений с управляемым откатом | Сохранённые снимки только затронутых свойств; проверка конфликтов перед восстановлением, чтобы не затереть последующие правки дизайнера. |

Первым следующим шагом рекомендуется аудит навигации: он поможет проверять
кликабельные гайды после массовых изменений. Остальные пункты — предложения,
не реализованные функции. Сроки и оценки трудозатрат пока не определены.
