# Проверка проекта — 7 сентября 2026

Проверено текущее рабочее дерево, включая незакоммиченные исправления реконструкции. Проверка охватила сервер MCP, broker и клиент соединения, генераторы операций Figma, чтение и экспорт ресурсов, схемы, установку, запуск OpenCode, CI и документацию. Это инженерная проверка проекта, а не гарантия отсутствия всех ошибок.

## Исправления

- Доводка размеров и отражений перенесена внутрь общей операции создания. При сбое новая реконструкция откатывается вместе с восстановлением выделения. Сравнение и PNG остаются после записи.
- Обрыв соединения после отправки изменяющей команды сохраняет `operationStatus: unknown`, код ошибки, целевой файл и следующий шаг. Автоматического повтора записи нет.
- Ветки, явно удаляемые или заменяемые через `changes`, исключаются из сбора ресурсов. Их видео, Grid и недоступные шрифты больше не блокируют итоговую сборку. Полнота чтения исходного дерева всё ещё обязательна.
- `RECONSTRUCTION_BLOCKED` возвращает список блокирующих слоёв с именами, ID и причинами. Ошибки до отправки записи имеют статус `not_applied`.
- Windows-лаунчер OpenCode вызывает npm `.cmd`-обёртку через `call` и возвращает фактический код завершения процесса.
- Добавлены `schema:check`, проверка схемы в CI и тесты запуска клиента. Обновлены README и описание ограничений реконструкции.

Ранее внесённые исправления масок, поворотов групп, отражённых векторов, смешанных радиусов и открытых контуров сохранены.

## Что остаётся

1. **Зависимость `qs@6.15.3`.** `npm audit` сообщил об одной уязвимой транзитивной зависимости средней тяжести, без high/critical: GHSA-x5fp-wj9c-mxmx и GHSA-4mjr-xmp4-gh2g. Две попытки обновления упёрлись в сетевые тайм-ауты npm и использовали устаревший кэш. Версия и lockfile не изменились; исправление зависимости не подтверждено. После восстановления доступа к npm выполнить `npm update qs --ignore-scripts --no-audit --prefer-online --prefix plugins/figma-local-bridge`, проверить фактическую версию, повторить `npm audit` и тесты.
2. **Работающие процессы.** Старый broker и открытый плагин Figma не подтверждают актуальную сборку. Обновление файлов на диске их не перезапускает. После завершения текущих операций нужно закрыть Bridge и AI-клиенты этого MCP, дать broker завершиться по простою и открыть приложения заново.
3. **Видео в реконструкции.** Перенос текущего видео остаётся неподдержанным: Figma отклоняет исходный hash. Автоматическая подмена видео картинкой не выполняется. Grid, skew и отражённые контейнеры также остаются ограничениями.

Коммит и публикация изменений не выполнялись. Ранее существовавшее изменение `.gitignore` сохранено.
