# Проверка проекта — 7 сентября 2026

Первичная проверка охватила исправления реконструкции, позже сохранённые в коммите `22215b9`: сервер MCP, broker и клиент соединения, генераторы операций Figma, чтение и экспорт ресурсов, схемы, установку, запуск OpenCode, CI и документацию. Это инженерная проверка проекта, а не гарантия отсутствия всех ошибок.

## Исправления

- Доводка размеров и отражений перенесена внутрь общей операции создания. При сбое новая реконструкция откатывается вместе с восстановлением выделения. Сравнение и PNG остаются после записи.
- Обрыв соединения после отправки изменяющей команды сохраняет `operationStatus: unknown`, код ошибки, целевой файл и следующий шаг. Автоматического повтора записи нет.
- Ветки, явно удаляемые или заменяемые через `changes`, исключаются из сбора ресурсов. Их видео, Grid и недоступные шрифты больше не блокируют итоговую сборку. Полнота чтения исходного дерева всё ещё обязательна.
- `RECONSTRUCTION_BLOCKED` возвращает список блокирующих слоёв с именами, ID и причинами. Ошибки до отправки записи имеют статус `not_applied`.
- Windows-лаунчер OpenCode вызывает npm `.cmd`-обёртку через `call` и возвращает фактический код завершения процесса.
- Добавлены `schema:check`, проверка схемы в CI и тесты запуска клиента. Обновлены README и описание ограничений реконструкции.

Ранее внесённые исправления масок, поворотов групп, отражённых векторов, смешанных радиусов и открытых контуров сохранены.

## Что требует продолжения

1. **Перезапуск работающих процессов.** Живой `get_status` подтвердил соединение с Task5, но broker и открытый плагин по-прежнему не сообщают актуальные ревизии. Обновление файлов на диске их не перезапускает. После завершения текущих операций нужно закрыть Bridge и AI-клиенты этого MCP, дать broker завершиться по простою и открыть приложения заново. Затем выполнить `node plugins/figma-local-bridge/scripts/verify-install.mjs --opencode --require-current`.
2. **Видео в реконструкции.** Повторное чтение узла `6001:4300` подтвердило исходную VIDEO-заливку. Ранее её запись отклонялась Figma с `Invalid SHA1 hash`; поддержка переноса этого видео не подтверждена. Для загрузки нового видео [createVideoAsync](https://developers.figma.com/docs/plugins/api/properties/figma-createvideoasync/) требует исходные байты файла, которых в проекте нет. Автоматическая подмена видео картинкой не выполняется. Grid, skew и отражённые контейнеры также остаются ограничениями реализации; поддержка этих свойств требует отдельной реализации и проверки в Figma.
