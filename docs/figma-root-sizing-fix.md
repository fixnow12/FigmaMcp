# Сохранение размеров корня при реконструкции · 12 сентября 2026

Исправлено расхождение `FIXED → HUG`, найденное во время
[первого измерения](figma-baseline-2026-09-12.md). Режимы размеров
восстанавливались у дочерних узлов, но корень явно пропускался. Проверка
результата сравнивала геометрию, тексты и шрифты, поэтому одинаковая текущая
ширина скрывала изменение режима.

## Изменения

- Корень участвует в восстановлении допустимых режимов ширины и высоты после
  создания дочерних узлов.
- Результат дополнительно проверяет обе оси корня. Несовпадение попадает в
  `verification.differences`, даже если текущая геометрия совпадает.
- `verification.rootSizing.checked` перечисляет проверенные поля,
  `skipped` — пропущенные с причиной. Исходный `FILL` относительно Auto Layout
  родителя не переносится на новый корень внутри SECTION; такой случай явно
  исключён из подтверждённых проверок.
- При запрошенном отключении Auto Layout прежний HUG контейнера становится
  FIXED. Дети сохраняют прочитанные координаты. Явные размеры и координаты из
  `changes` имеют приоритет независимо от порядка обновлений родителя и ребёнка.
- Области проверки теперь называются `source-geometry-text-fonts-and-root-sizing`
  и `retained-nodes-text-fonts-and-root-sizing`.

Восстановление выполняется внутри прежней операции с откатом; проверка после
записи остаётся только чтением. Новых вызовов MCP, повторов или отключённых
проверок нет. Скоростных оптимизаций этот патч не содержит.

- отключение Auto Layout с прежним HUG вызывает недопустимое присваивание;
- дети теряют позицию при отключении Auto Layout.
