## Исправленные дефекты проекта

### Ложный конфликт после записи NAVIGATE

Все 14 вызовов `set_reactions` в экспорте вернули ошибку: 12 `partial`,
2 `rolled_back`. Чтение подтверждало, что переходы фактически сохранялись.
Причина — Plugin API добавляет `resetVideoPosition:false`, которого не было
в аргументах. Bridge учитывал алиасы `action`/`actions` и порядок полей,
но считал добавленный default конкурентным изменением.

В `src/interactions.mjs` нормализуется только сравнение отсутствующего
`resetVideoPosition` с `false` у NODE-действий. Запрашиваемое значение
не заменяется фактическим снимком. `true`, другая цель и неизвестные поля
по-прежнему обнаруживаются как конфликт; безопасный откат сохраняется.

Регрессии используют форму входа и read-back из экспорта. Проверены пакет,
повтор без дублей, отказ setter после записи, отказ следующего узла и
сохранение настоящих внешних изменений.

### SVG dryRun пропускал ошибку пропорций

SVG с viewport/viewBox 183 × 40 и запрошенным размером 182.14 × 40
проходил `dryRun`, после чего запись падала и откатывалась.

В `src/figma-code.mjs` preflight теперь проверяет известные размеры корневого
SVG без создания узлов с тем же допуском 0.1 px, что и прежний `sizeSvg`.
Числовые/px width и height имеют приоритет над viewBox. При отсутствии обоих
используется viewBox. CSS, относительные единицы и неполные размеры не
угадываются; окончательная проверка импортированного узла сохранена.

## Ошибки аргументов и выводов OpenCode

Схема корректно отклоняла `strokeWeight`, нулевую ширину LINE и элементы
`spec.nodes` без `type`/`key`/`name`. Служебный ключ был передан как `id`,
хотя для него существует поле `key`. Эти отказы не требуют ослабления API.

Уточнены инструкции `figma-local` и справочники:

- примеры `id` и `key`, `strokeWidth` и построения вертикальной линейки;
- проверка каждого изменённого сохранённого пакета перед отправкой;
- dryRun подтверждает только переданную спецификацию и её шрифты;
- пустые коллекции Variables не доказывают отсутствие внешних компонентов;
- после `partial` сначала читать затронутые узлы, а не повторять запись
  по одному узлу и считать одинаковые ошибки штатным успехом.
