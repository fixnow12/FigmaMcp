# Режимы Variables на точных узлах

В рамках согласованного сохранения гайд-примеров добавлен типизированный `set_node_variable_modes`. Он принимает обязательный `fileKey` и до 40 `bindings: [{nodeId, collectionKey, anchorVariableKey, modeName}]`; повторяющаяся пара узел/коллекция запрещена. Ключи ресурсов — 40 hex-символов. Цели — FRAME/INSTANCE текущей страницы, без разрешения менять определения компонентов.

До любой записи весь пакет проверяет узлы, страницы, импорт anchor, ключ коллекции, единственный режим с заданным именем, текущие шрифты всех текстовых потомков (включая скрытых; предел 2000 узлов), неизменность структуры и прежних явных режимов. Изменение значений коллекций не выполняется. Уже совпавший режим — точный no-op. Setter error откатывает собственные изменения в обратном порядке; сторонний конфликт сохраняется с `partial`.

Ответ: `{fileKey,pageId,variableModesVerification:{checks:[{id,collectionKey,modeName,collectionId,modeId,mutated}]}}`. Каждый фактический collection ID из `explicitVariableModes` разрешается через API: требуется точный ключ коллекции и единственное имя/ID режима. Это поддерживает свежие узлы без bindings, где Figma записывает исходный ID коллекции вместо ID импортированного anchor. Полная map проверяется после async lookup, перед каждой записью и в общем синхронном финальном guard; rollback восстанавливает прежнюю фактическую identity только при точном совпадении собственной записанной map. GuideConstructor сверяет точное покрытие запроса, узлы, file/page, collectionKey/modeName и непустые mode/collection IDs до продвижения cursor. Отдельная инспекция нужна для независимого подтверждения живого результата.

Capability: `node-variable-modes-v1`, только при готовом актуальном runtime в указанном файле. Frozen revisions: source `679336bd7ef17f2a`, broker `e39d2f39874204aa`, plugin `c8e5c8716961ba78`. После завершения всех записей вызов `get_status` точного файла запускает штатное обслуживание устаревшего broker; дождаться повторного READY с совпавшими revisions. Не перезапускать broker при active/uncertain операциях.
