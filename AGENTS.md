# Инструкции для агента

- Общаться с пользователем только на русском языке.
- Для любых задач, связанных с чтением или изменением макета Figma, сначала прочитать `plugins/figma-local-bridge/skills/figma-local/SKILL.md` и следовать ему.
- Для работы с холстом использовать только MCP-сервер `figma-local`. Не открывать Figma через браузер и не редактировать холст мышью или клавиатурой.
